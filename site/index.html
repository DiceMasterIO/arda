How it works

Geology first. Then water. Then people.

Arda builds a world the way a world is built: each layer only uses what the layer beneath it already settled.

  1. i.Seed and shapeA seed and an extent fix everything. Plates collide into ranges; winds by latitude carry the rain.
  2. ii.Weather the landHillslopes diffuse, glaciers carve troughs, and erosion runs across area edges so no seam becomes a wall.
  3. iii.Let the water find its wayConnected drainage and an annual water balance: lakes only where there is a basin and the rain to fill it.
  4. iv.Settle itTowns where the land can feed them, ports where ships can reach, roads with grade limits, balanced realms.
  5. v.Give it a pastNamed events, causal histories, notables and a gazetteer of seas, capes, forests and ranges.
  6. vi.Serve every scaleAtlas and political maps up to 32K, JSON, and battle maps on demand from a frozen /v1 HTTP API.
DeterministicSame seed, same configuration, same generator: the same world, byte for byte. CI checks a golden world on Linux, macOS and Windows.
Saved, not re-rolledThe world is written once as binary layers. Every map and export reads it back; higher resolution never changes the land.
Built for the tableBattle maps follow one rules contract: walls block, stones are difficult terrain, torchlight stops at walls.

Tutorial · about ten minutes

Your first world, start to battle map.

Five steps take you from nothing to a populated continent and a five-foot grid you can drop into a VTT. Start with MICRO: eight areas, 102 × 204 km, ready in seconds.

Drop --micro for a full 500 × 1000 km continent, or pick your own with --size 300x600. Full reference in the README.

  1. Install Grab a prebuilt binary from Releases (Linux, macOS, Windows), pull the Docker image, or build from source with stable Rust. 
    git clone https://github.com/DiceMasterIO/arda.git
cd arda
cargo install --path crates/arda-cli --locked
  2. Generate the land Relief, climate, erosion, rivers and lakes, saved as binary layers under worlds/w42/. 
    arda generate --seed 42 --micro --out worlds/w42
  3. Settle it Towns, roads, realms and names; then town plans, politics, history and notables. 
    arda settle --world worlds/w42
arda society build --world worlds/w42
  4. Draw the maps An Atlas overview, a political map, or any area at up to 32K. 
    arda export --world worlds/w42 --overview --style atlas --out maps
arda export --world worlds/w42 --overview --style atlas --society political --out maps/political
arda export --world worlds/w42 --area 1,1 --style atlas --quality 16k --out maps
  5. Serve it and step inside Start the read-only server, then ask for the battle map of any 100 m cell. 
    arda-server --world worlds/w42
curl -o market.png http://127.0.0.1:8787/v1/tactical/cell/546/658.png

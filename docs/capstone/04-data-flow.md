Final area composition does not mutate those physical authorities. Complete admission conservatively sums all owned-payload reservations, including 53 bytes per modeled fine cell plus container headers for terrain on the current 64-bit layout, alongside the water sums. ## Failure paths

Admission failure leaves output untouched. Later typed topology, forcing, arithmetic, capacity or I/O failures retain an incomplete output without a completion manifest; a clean new target is required. Existing files are refused, never interpreted as a resumable checkpoint. Create-new reservation prevents cooperating generators sharing a destination. The same-directory final manifest rename provides process-interruption semantics; power-loss durability is not promised (`crates/arda-gen/src/orchestrator/publication.rs`).

Original nested causes propagate through typed errors to CLI anyhow context. Loading a missing/corrupt requested layer fails lazily; area payload length is admitted before allocation. Atlas propagates corrupt or absent in-world neighbors and rejects unset, duplicate or contradictory halo directions; genuine out-of-world directions are accepted (`crates/arda/src/atlas.rs:35`, `crates/arda-render/src/atlas.rs:99`, `crates/arda-render/src/atlas.rs:174`). Overview propagates area failures, and area JSON propagates serialization errors (`crates/arda/src/world.rs:208`, `crates/arda-render/src/json.rs`). Quality PNG paths stream into an exclusive temporary sibling, flush/close, and rename only after success; ordinary failure preserves a previous completed destination and attempts temporary cleanup. Abrupt termination may retain the temporary file, and power-loss durability is not promised (`crates/arda/src/export_quality.rs:128`). Legacy Classic Detail/block/JSON and explicit preview `--px` still finish rendering/serialization before `std::fs::write`; a write failure can leave a partial destination (`crates/arda/src/lib.rs`, `crates/arda-cli/src/main.rs:221`).

Unchanged tactical WFC tries attempts 0–7, then emits a flagged relaxed fallback. No new timeout, panic-recovery or resume policy is introduced (`crates/arda-gen/src/block/wfc.rs`).

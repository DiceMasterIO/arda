# Arda branding

Selected direction: circular world with a river cut, beside lowercase **arda** in **Ubuntu Sans**.

The repository README uses [../logo.svg](../logo.svg) with a plain HTML
`img`, matching Capstone's format. That SVG switches its lettering colour
through an embedded media query and keeps a transparent background.

| Intended background | Lettering | SVG | PNG |
| --- | --- | --- | --- |
| Dark mode | Ivory `#ECEAE4` | [Vector](arda-logo-dark.svg) | [1904 × 800](arda-logo-dark.png) |
| Light mode | Charcoal `#171C21` | [Vector](arda-logo-light.svg) | [1904 × 800](arda-logo-light.png) |

All exports linked above have transparent backgrounds, including the river cut
through the symbol. The symbol is sage green `#80AD92` in both modes. Mode names
describe the background on which the logo is intended to appear; no background
is included in the files.

SVG lettering is outlined, so no font installation is required. PNG exports use
RGBA with an alpha channel. Only the final light/dark logos, the README's adaptive
logo, and the social sharing image are retained.

# Data flow

## Lifecycles

1. **Generate/admit:** CLI `run_generate` → public `generate` → `generate_world_with_limits` → pure resource admission, then fresh output reservation (`crates/arda-cli/src/main.rs`, `crates/arda/src/lib.rs`, `crates/arda-gen/src/orchestrator.rs`, `crates/arda-gen/src/orchestrator/generation_limits.rs`). Up to five deterministic continent attempts apply the 250–900‰ land gate and require a major river reaching sea; the designed 1,500 m range gate remains absent.
2. **Continent:** seeded plates, 20 tectonic steps on 4 km cells, normalized radial coast construction, 1 km relief and erosion precede climate/hydrology. The coast mask uses integer Euclidean distance instead of max-axis square contours. Climate does not feed rainfall back into tectonic erosion. Current marine classification is rim-connected nonpositive terrain; temperature uses hemisphere-symmetric latitude and signed nonmarine lapse (`crates/arda-gen/src/continent/mod.rs`, `crates/arda-gen/src/continent/coast.rs`, `crates/arda-gen/src/continent/climate.rs`). Naming and human geography remain unbuilt.
3. **Canonical preparation:** initialize one whole modeled rectangle using bounded symmetric affine-preserving regional relief and aligned area-detail octave lattice spacings 40/20/10/5 cells. Run 40 shared evolution iterations with whole-domain fractional MFD contribution, a shared uplift maximum, creep, physical-spill protection and implicit downstream-first incision against updated receiver beds, followed by collapse. Area cuts do not pin heights or taper uplift; only the actual modeled outer rim stays fixed. Freeze the result and copy each tile's valid cells, including partial fringe, into immutable prepared height/annual-rain/unclamped-temperature records. Outside-valid container padding is never serialized. Release the dense surface before the shared water solve. Each modeled axis is `max(requested_km*10, exported_area_count*512)` (`crates/arda-gen/src/area/prepare.rs`, `crates/arda-gen/src/area/evolution.rs`, `crates/arda-gen/src/continent/area_detail.rs`, `crates/arda-gen/src/hydrology/prepared_domain.rs`).
4. **Shared topology:** page prepared cells into actual fine ocean connectivity, receiver/flat-distance/terminal ownership, physical saddles, witnessed MST and contracted hierarchy. Physical bed stays distinct from routing order and lake surface. A disconnected negative depression can remain inland. Spills are bound to actual pre-event source components and receiving cells (`crates/arda-gen/src/orchestrator/shared_solve.rs`, `crates/arda-gen/src/hydrology/routing.rs`, `crates/arda-gen/src/hydrology/hierarchy.rs`, `crates/arda-gen/src/hydrology/witness_binding.rs`).
5. **Annual water:** canonical cells supply precipitation P, twelve-month climatological evaporation E, baseline land loss `A=min(P/2,E)` and dry source `R=P-A`. Exact physical bands consume additional wet support `D=E-A`; partial support is an explicit marginal debit. This static convention chooses a representative surface, not weather/calendar/groundwater/snow evolution. Positive depth defines wet membership. Signed accepted-tree transfers and fine flow replace wet source with `P-E`, suppress internal same-lake flow, and reconcile sea/domain export exactly (`crates/arda-gen/src/hydrology/annual_aggregation.rs`, `crates/arda-gen/src/hydrology/annual.rs`, `crates/arda-gen/src/hydrology/fine_flow.rs`, `crates/arda-gen/src/hydrology/annual_records.rs`).
6. **Final areas:** compute directed drainage/order/HAND, build stable global records and area references, then compose saved cells and local fragments from immutable shared authority. Channels initiate at 40 L/s. No coarse inflow is injected and no 300-cell/4 m local lake filter defines published water. Final temperatures use the solved fine marine mask. Vegetation/society/roads remain largely default fields (`crates/arda-gen/src/hydrology/flow_metrics.rs`, `crates/arda-gen/src/hydrology/final_index.rs`, `crates/arda-gen/src/hydrology/area_output.rs`, `crates/arda-gen/src/area/shared_compose.rs`).
7. **Blocks and publication:** sampled land cells at a 64-cell stride call unchanged `constraints_for`/`fill_block` and write one compressed archive per area. The 24-tile vocabulary and simple constraints remain; detailed assets, coherent buildings and complete coverage are not added. Global hydrology/coarse tables follow area writes. Flush and drop scratch owners, remove scratch, then rename the staged manifest last (`crates/arda-gen/src/orchestrator.rs`, `crates/arda-gen/src/orchestrator/global_output.rs`, `crates/arda-gen/src/orchestrator/publication.rs`).
8. **Load/query:** `World::load` reads and validates the manifest only, creating empty area/archive cache slots. `area()` caches a requested tile; `read_area()` returns an owned uncached tile. Block access reads/decompresses the containing whole-area archive independently. Missing layers can fail when first requested (`crates/arda/src/world.rs`).
9. **Export:** CLI validates mode → manifest load → requested saved data → renderer/serializer → output write. Area PNG uses 512² preview or 4096² detail over unchanged 100 m cells. Saved physical edges and bounded junction context define coverage; only preview adds a bounded readability mark. Blue standing-water shade comes from actual depth. Overview processes one owned area at a time; block rendering retains 8 px squares. JSON schema 2 includes connected annual semantics (`crates/arda-cli/src/main.rs`, `crates/arda/src/lib.rs`, `crates/arda-render/src/carto.rs`).
10. **Preview command:** generate a full world, then export overview; this still includes areas and sampled blocks, not a continent-only shortcut (`crates/arda-cli/src/main.rs`, [preview scenario](logic/07-preview.md)).

## State

Generation first owns dense shared terrain inputs and scratch, then immutable prepared files, bounded mutable routing/flow/hierarchy stores, annual arrays and final indices inside its private transaction. Final area composition does not mutate those physical authorities. Complete admission conservatively sums all owned-payload reservations, including 53 bytes per modeled fine cell plus container headers for terrain on the current 64-bit layout, alongside the water sums. It also admits scratch, logical work and requested I/O ceilings; defaults are 16 GiB RAM/256 GiB scratch with separate finite leaf/band/record/reference caps. MICRO and default sizes fit default RAM; 4000×4000 km is refused unless explicitly larger limits are supplied. RAM admission is not a process-RSS guarantee (`crates/arda-gen/src/area/evolution.rs`, `crates/arda-gen/src/hydrology/types.rs`, `crates/arda-gen/src/orchestrator/generation_limits.rs`, `crates/arda-gen/src/orchestrator/generation_limits_tests.rs`).

The current shared-terrain correction has completed a MICRO generation and export check, while its full candidate run remains under verification. Natural-realism acceptance is open; earlier candidate02 timings and frozen-panel results describe the pre-correction flow, including its former per-area erosion stage.

Published state is the completed world directory. `World` retains only requested area/archive caches; uncached exports drop each owned area after use. There is no application server state, session store, database or frontend cache in this repository (`crates/arda/src/world.rs`).

## Side-effect boundaries

Prepared/routing/flow/hierarchy stores own counted scratch I/O. `WorldOutput` reserves names and writes final layers; public codecs validate records. Manifest helpers and the loading/export facade perform filesystem I/O. No runtime network calls occur (`crates/arda-gen/src/orchestrator/publication.rs`, `crates/arda/src/world.rs`, `crates/arda/src/lib.rs`).

## Failure paths

Admission failure leaves output untouched. Later typed topology, forcing, arithmetic, capacity or I/O failures retain an incomplete output without a completion manifest; a clean new target is required. Existing files are refused, never interpreted as a resumable checkpoint. Create-new reservation prevents cooperating generators sharing a destination. The same-directory final manifest rename provides process-interruption semantics; power-loss durability is not promised (`crates/arda-gen/src/orchestrator/publication.rs`).

Original nested causes propagate through typed errors to CLI anyhow context. Loading a missing/corrupt requested layer fails lazily; area payload length is admitted before allocation. Overview propagates area failures, and area JSON propagates serialization errors. Rendering/serialization finish before `std::fs::write`, but a failed filesystem write can still leave a partial export (`crates/arda/src/world.rs`, `crates/arda/src/lib.rs`, `crates/arda-render/src/json.rs`).

Unchanged tactical WFC tries attempts 0–7, then emits a flagged relaxed fallback. No new timeout, panic-recovery or resume policy is introduced (`crates/arda-gen/src/block/wfc.rs`).

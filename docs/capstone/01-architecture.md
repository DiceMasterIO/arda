## Composition

`main` parses clap once and dispatches each `Command` variant to its private handler; handlers build configuration or parse coordinates, load through `World`, and call only the facade (`crates/arda-cli/src/main.rs:271`). There is no DI container: dependencies are plain values, references, closures, and concrete memory/file stores (`crates/arda/src/export_quality.rs:20`, `crates/arda-render/src/overview/streaming.rs:30`).

The generator admits the full request before reserving a fresh output, generates and validates a continent, evolves the complete modeled terrain once, persists immutable prepared tiles, releases the dense terrain, runs one shared annual-water solve, builds its final index, then composes and writes each exported area (`crates/arda-gen/src/orchestrator.rs:344`, `crates/arda-gen/src/orchestrator.rs:357`, `crates/arda-gen/src/orchestrator.rs:406`, `crates/arda-gen/src/orchestrator.rs:422`, `crates/arda-gen/src/orchestrator.rs:441`, `crates/arda-gen/src/orchestrator.rs:450`). Global/coarse layers precede final manifest publication; the manifest rename is the completion stamp (`crates/arda-gen/src/orchestrator.rs:464`, `crates/arda-gen/src/orchestrator.rs:480`, `crates/arda-gen/src/orchestrator.rs:535`).

Preparation, shared solving, and final area composition execute sequentially. Uplift, fractional MFD contributing area, creep and collapse cross publication-area boundaries; only the modeled outer rim remains fixed. No final area reads another final area file: physical neighbor data comes from the shared prepared domain, so crossings do not depend on output order (`crates/arda-gen/src/orchestrator.rs:406`, `crates/arda-gen/src/orchestrator.rs:450`). Dense terrain and water-stage memory/file work are admitted before publication; insufficient limits leave the requested output path untouched (`crates/arda-gen/src/orchestrator.rs:332`, `crates/arda-gen/src/orchestrator.rs:344`).

Admission accounts for dense terrain inputs and scratch at 53 bytes per modeled fine cell plus container headers on the current 64-bit layout, conservatively summed with water-stage reservations (`crates/arda-gen/src/orchestrator/generation_limits.rs`). Default and MICRO requests fit the default 16 GiB allowance; a 4000×4000 km request requires larger explicit limits and is refused before output creation under defaults (`crates/arda-gen/src/orchestrator/generation_limits_tests.rs`). Candidate06 completed five-world validation with fewer repeated pond patterns; parallel drainage and large regional basin geometry remain recorded open, while candidate02 records the preceding implementation (`docs/capstone/changelog.md`, `docs/capstone/open-items.md`).

Quality exports compose the stored world with renderer-owned display resolution. `ImageQuality` validates one edge and derives an aspect-preserving overview size; area `Custom` scale maps that edge onto the unchanged 512×512 saved cell grid (`crates/arda-render/src/quality.rs:9`, `crates/arda-render/src/quality.rs:41`, `crates/arda-render/src/channels.rs:11`). Exact overview exports use 256-row raster bands and may reload an uncached area for each intersecting band, keeping 32K output bounded without retaining the complete image (`crates/arda-render/src/overview/streaming.rs:9`, `crates/arda-render/src/overview/streaming.rs:15`, `crates/arda/src/export_quality.rs:67`). Legacy `export_overview` retains the full raster and remains the CLI path for Preview `--px` and a public library entry point (`crates/arda/src/lib.rs:146`, `crates/arda-cli/src/main.rs:191`).

Atlas's per-pixel sampler uses exact rational saved-cell centers when an area's output partition is at least 512 pixels along that axis, and the existing half-open box footprint when smaller. It filters samples to the owning terrain class, averages RGB palette and Q12 light separately, then modulates once; land alone receives directional relief, sea uses saved negative height, and area lake/channel authority stays in the existing rendering path (`crates/arda-render/src/atlas.rs:302`, `crates/arda-render/src/atlas.rs:418`, `crates/arda-render/src/overview.rs:239`, `crates/arda-render/src/channels.rs:448`). Atlas and Classic share the bounded 256-row overview pipeline, including unequal area partitions and possible rereads across bands (`crates/arda-render/src/overview/streaming.rs:55`, `crates/arda-render/src/overview/streaming.rs:100`).

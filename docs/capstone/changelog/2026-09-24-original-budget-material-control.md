# Original-budget material control

The user explicitly requires reduced repetition while retaining the preferred baseline's rugged detail. An audit found that the previous matched material comparison used roughly half the baseline's initial removal. A separately declared control now tests the exact same saved material field at the original starting amount, using one gain fixed before evolution. No field, wavelength or visual tuning was performed.

Two 1024 runs complete in 176.74/176.09 seconds, with exact seven-field replay, original-unit baseline parity, finite fields, unchanged rims and exact first-step matching. The new final central RMS neighbor slope is 0.7663 versus 0.7744 for the original, while mean net lowering is 17.163 versus 18.131 m. These numerical results do not establish appearance acceptance.

Actual Arda views retain much more rugged contrast than the old lower-budget arm, but prominent parallel grooves remain. Root and independent visual review decline the conditional 2048 continuation. The preferred completed baseline and all 523 original saved-world files remain unchanged. No production changes or new 32K render.

An initial comparison-render parity check caught float32 sampling where the old comparison used float64. The failed frozen script/output is retained; a separately frozen correction restores exactly the old sampling for every arm and all eight old PNGs reproduce byte-for-byte. Terrain and appearance settings were unchanged.
